# Repülőjegy Foglalási Rendszer

Többfájlos Python konzolos alkalmazás repülőjegy-foglaláshoz.

## Futtatás

```bash
python main.py
```

## Fájlok

- `main.py` - belépési pont
- `foglalasi_rendszer.py` - menük, foglalási logika, JSON mentés/betöltés
- `jarat.py` - járatok és indulások
- `legitarsasag.py` - légitársaság osztály
- `jegyfoglalas.py` - foglalás osztály
- `foglalasok.json` - mentett foglalások
